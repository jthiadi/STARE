Assembly monitoring on IndustReal: pipeline overview

Goal: from a worker's head-mounted camera, recognise the part in hand and the action, track SOP steps, and warn the moment a wrong part is picked up, before it is installed.

1. Planned final pipeline (live, with verb)

Perception never reads the SOP. The SOP is only used afterwards to judge what was seen, so an alarm cannot be caused by the SOP itself.

Who detects what: DINOv2 = the eyes (describes each frame as numbers, gives no part name and no location) → TCN = the brain (reads those descriptions over time and decides the part name + confidence) → SAM = the pointer (finds where that part is: outline at the hand). The part name comes only from the TCN.

A1 + A2: what is the part? (DINOv2 sees, TCN decides)

  1. Frames: video sampled at 10 frames/s.
  2. Views per frame: full frame, centre crop, hands crop (fixed lower-middle region, not a hand detector), high-res hands crop pooled into a 2×2 grid.
  3. Frozen DINOv2-small turns each view into a feature vector (image content only, no timing).
  4. Fine-tuned DINOv2-small on hands crops (part + verb labels), 2-fold cross-fitted so no video is featurised by a model that trained on it.
  5. Progress feature added: how far through the video each frame is (0 → 1). Needs total video length, so offline only.
  6. Multi-stage temporal CNN (MS-TCN style) labels every frame with a part or "nothing"; a verb head is trained alongside to help. Sees ~100 s of future frames.
  7. Ensemble of seeds/folds and two variants, weighted on training out-of-fold results.
  8. Viterbi smoothing over the whole video with learned part-to-part transition costs. Needs the full video.
  9. Output: part name + confidence (0–1) for every frame. No SOP input anywhere.

A4: where is the part? (SAM, display only)

  1. SAM 3.1 per frame with text prompts for 15 kit parts + hand (monitor/kit_catalog.py) → outlines.
  2. Candidates: outlines that touch a hand (hand mask widened 12 px, ≥4% of the part touching).
  3. Ignore parts already on the model: skip outlines that sit still (same place 1.5 s and 3 s ago).
  4. Loose name check: SAM's name must be in the same look-alike group as the model's part (nut/washers/acorn nut; pins; white frame parts). Wheel and pulley are kept apart.
  5. Keep the same object across frames while it stays valid (tracking).
  6. Nothing qualifies → no box, header shows "not located in hand" (never a wrong box on purpose).
  7. Label on the box = model's part + confidence. SAM's own name is not shown.

C1 + C3: SOP steps (rule-based baseline)

  1. Ready steps from the SOP graph: prerequisites all done.
  2. Each step has a moving part (e.g. pin) and a target (e.g. chassis) from the SOP.
  3. Evidence per frame from SAM boxes: hand near moving part, part moving, part box touching target box.
  4. Timers: enough work time, contact held, then hand leaves and stays away → step marked done.
  5. Limits: never checks the part is actually inserted/screwed; some timers were tuned on this video; SAM names are unreliable.

D1: overlay video (first 3 min 20 s)

  1. Top: official label (for checking) vs model part + confidence, MATCH/MISS.
  2. Image: hand outlines; part in hand outlined and labelled with the model's part + confidence.
